Flow Preview Interaktif

Tiga perjalanan dipisah jelas: Admin (membuat & mengelola kartu), Pembeli (aktivasi kartu), Pelanggan (scan kartu aktif → review). Semua memakai endpoint & database yang sama dengan mode normal. Data demo disimpan terpisah dari data produksi.

DEMO_MODE nonaktif. Login demo & redirect review simulasi tidak tersedia. Set DEMO_MODE=true di .env lalu restart.

3

Aktivasi

Isi Activation Code & link Google Review.

Endpoint: POST /api/activate. Validasi: kode salah → 401, sudah aktif → 409, tidak ditemukan → 404, URL salah → 400.
1

Pelanggan memakai kartu aktif

Pilih kartu ACTIVE, lalu simulasikan scan/tap.

Alur: Scan QR / Tap NFC → Catat kunjungan → Redirect ke Google Review
